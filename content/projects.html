Tournament of Albums

Obviously, it is extremely important that I be able to rank all the albums in my music collection, but I have found it is too difficult to rank them all at once. This is my attempt to do it piecemeal, in small batches, with scores aggregated by applying my highly scientific probabilistic model.

The Tournament of Albums consists of three parts:

  • A static web app, served from S3 and CloudFront.
  • A read-only API, with one Lambda per endpoint.
  • A data pipeline that picks up new match results, applies the model, and writes the scores to DynamoDB for the API to serve.

Data Packages

NJ OAG Use Of Force Data Package for R

NJOAGUOF

This data package is a cleaned-up version of the NJ OAG Use of Force dataset available from https://www.njoag.gov/force/.

There is also an interactive dashboard built to illustrate the package: a map of New Jersey use-of-force reports. The source code is here.

NJ Elections Data Package for R

NJELECTIONS

This is a data package for R containing the results of statewide elections in NJ, from 2004 to 2025.

NJ Municipalities Data Package for R

NJMUNICIPALITIES

This is a data package for R that contains every county and municipality in New Jersey, from 2000 to 2025.
